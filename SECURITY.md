# Polityka bezpieczeństwa (Security Policy)

## Zakres

Polityka dotyczy kodu w repozytorium KryptoSymulator BTC. Aktualna aplikacja jest statycznym symulatorem i nie obsługuje kont użytkowników, prawdziwych środków, kluczy prywatnych ani połączeń z kontami giełdowymi.

Projekt był vibecoded z pomocą narzędzi AI i nie przeszedł profesjonalnego audytu bezpieczeństwa. Nie należy zakładać, że brak znanych podatności oznacza brak błędów.

## Zgłaszanie podatności

Jeżeli zauważysz problem bezpieczeństwa:
1. Nie publikuj od razu publicznego exploita, danych osobowych, sekretów ani instrukcji, które ułatwiłyby wykorzystanie problemu.
2. Sprawdź, czy repozytorium udostępnia prywatne zgłaszanie podatności w GitHub Security Advisories. Jeśli tak, użyj tej funkcji.
3. Jeśli prywatny kanał nie jest dostępny, utwórz minimalne publiczne zgłoszenie proszące o kontakt w sprawie bezpieczeństwa, bez szczegółów umożliwiających wykorzystanie błędu. Publiczne Issues nie są poufnym kanałem.

Repozytorium: https://github.com/qbachicken/krypto-symulator-btc

W zgłoszeniu opisz wpływ problemu, warunki jego wystąpienia i bezpieczny sposób odtworzenia. Nie dołączaj haseł, tokenów, kluczy API, fraz odzyskiwania portfeli ani danych innych osób.

## Oczekiwania

Nie gwarantujemy czasu odpowiedzi, terminu poprawki ani konkretnego wyniku zgłoszenia. Zgłoszenia są oceniane w dobrej wierze, ale utrzymanie projektu może być ograniczone. Nie podejmuj działań testowych na cudzych systemach ani usługach zewnętrznych bez upoważnienia.

## Działania użytkownika

Nie wpisuj prawdziwych poświadczeń do symulatora. Aktualna aplikacja nie potrzebuje haseł, kluczy prywatnych, fraz seed ani kluczy API użytkownika. Jeśli takie dane zostaną przypadkowo ujawnione publicznie, załóż, że mogły zostać skopiowane i unieważnij je u właściwego dostawcy.

## English summary

Please report security issues responsibly. Do not post exploit details, personal data, credentials, API secrets, or recovery phrases in public issues. Use GitHub's private vulnerability reporting if it is enabled; otherwise, open a minimal public issue requesting a private contact route without including sensitive details. The project has not undergone a professional security audit and does not guarantee response or remediation timelines.
